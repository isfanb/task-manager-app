# 📝 Task Manager App

Task Management application that focuses on organized workflows and data. This app allows users to create, track, and filter tasks while ensuring safety through validation and confirmation dialogs.

---

## ✨ Features

### 🆕 Create Task
* **Modal Dialog:** Tasks are added via a clean, focused dialog window.
* **Required Validation:** Prevents empty entries. The system alerts the user if they attempt to save a task without a task and description.

### 🔄 Status Management
* **Progress Tracking:** Toggle tasks between **On Progress** and **Done**.

### 🔍 Advanced Filtering
* **Category Views:** Filter your entire list by status (**All**, **On Progress**, or **Done**) to declutter your workspace.

### 🛡️ Data Safety
* **Delete Confirmation:** Includes a safety dialog to confirm deletion, preventing accidental loss of task data.

---

## 🛠️ Tech Stack

* **Frontend:** Angular/ TypeScript
* **Styling:** Angular Material / CSS

---

## 🚀 Installation & Setup

Follow these steps to get the project running on your local machine:

1. **Clone the repository**
   ```bash
   git clone [https://github.com/your-username/task-manager-app.git](https://github.com/your-username/task-manager-app.git)
   ```
2. **Navigate to the project directory**
   ```bash
   cd task-manager
   ```
3. **Install Dependencies**
  ```bash
  npm install
  ```
4. **Run the application**
  ```bash
  ng serve --open
  ```
